# خريطة صقور العراق — مشروع Android / Android Auto

هذا مشروع Android Studio أولي يغلّف ملف HTML الأصلي داخل تطبيق أندرويد للهاتف، ويضيف شاشة Android Auto مبسطة لاختيار وجهة ثم تسليم الملاحة إلى Google Maps.

## ماذا يتضمن؟
- `app/src/main/assets/index.html`: ملف HTML الأصلي كما أُرسل، دون إعادة كتابة منطق الخريطة.
- `MainActivity.kt`: يعرض الخريطة داخل WebView، مع JavaScript وDOM Storage وتفعيل طلب إذن الموقع.
- `SuqoorCarAppService.kt`: شاشة Android Auto منخفضة التشتيت تعرض وجهات مختصرة، وعند اختيار وجهة تحاول فتح الملاحة في Google Maps.
- إعدادات Gradle وManifest أساسية لفتح المشروع في Android Studio.

## ما الذي لم يُنجز بعد؟
**هذا ليس بعد تطبيق ملاحة مستقلًا كاملًا على Android Auto.** شاشة السيارة هنا هي منتقي وجهات من فئة POI، وتسلّم التوجيهات خطوة بخطوة إلى Google Maps. لا ترسم خريطة HTML الأصلية على شاشة السيارة ولا تنقل تعليمات الانعطاف أو ETA أو بيانات المرور الخاصة بها إلى واجهة Android Auto.

لتحويله إلى تطبيق ملاحة مستقل يجب تنفيذ هذه الأجزاء:
1. نقل محرك المسارات والموقع إلى Kotlin/SDK أصلي مناسب، أو دمج SDK خرائط مرخص يدعم العرض داخل Surface الخاصة بـ Android for Cars.
2. تنفيذ `NavigationTemplate` و`NavigationManager`، تحديث `Trip` و`Step` بصورة صحيحة، الإرشاد الصوتي عبر قناة الملاحة، وإشعار الملاحة.
3. تنفيذ محاكاة الملاحة المطلوبة للاختبار، ومعالجة intents القياسية للملاحة.
4. اختبار سلوك شاشة السيارة مع Android Auto Desktop Head Unit، واختبار متطلبات الجودة والفئات قبل النشر.
5. تأمين Firebase إن كان مستخدمًا في الصفحة، ومراجعة قواعد قاعدة البيانات وعدم تضمين أسرار إدارية في التطبيق.

## ملاحظات على ملف HTML الأصلي
الصفحة تعتمد على الإنترنت لتحميل MapLibre GL وCSS والخطوط ومكتبات Firebase، كما تستخدم خدمات جغرافية خارجية مثل Nominatim وOverpass بحسب الميزات. لذلك لا تعمل كل ميزاتها دون اتصال، وقد تتأثر بالحصص والقيود وسياسات تلك الخدمات. إذا كان ملف HTML يعتمد على إعداد Firebase أو بيانات سرية غير موجودة/غير صالحة، فيجب ضبطها قبل توقع عمل المزامنة.

## فتح المشروع
1. فك ضغط الملف.
2. افتح مجلد `SuqoorIraqAndroidAuto` من Android Studio.
3. استخدم JDK 17 واترك Gradle يزامن الاعتماديات.
4. شغّل تطبيق الهاتف على جهاز Android فعليًا لمنح إذن الموقع وتجربة الخريطة.
5. اختبر تكامل السيارة عبر Android Auto Desktop Head Unit (DHU) أو سيارة متوافقة.
6. قبل نشر Google Play، استبدل `HostValidator.ALLOW_ALL_HOSTS_VALIDATOR` بإعداد مناسب للإنتاج، راجع سياسة الخصوصية والأذونات، واختبر كل متطلبات جودة تطبيقات السيارات.

## متطلبات البناء
- Android Studio حديث وJDK 17.
- اتصال إنترنت لتنزيل Gradle dependencies ولتحميل مصادر الخريطة الخارجية.
- جهاز Android مع Android Auto أو DHU للاختبار.
- Google Maps مثبت لتسليم الملاحة إليه (يوجد fallback إلى رابط خرائط الويب).
- نشر Android Auto يتطلب اختيار form factor المناسب في Play Console ومراجعة Google؛ نجاح البناء لا يعني القبول التلقائي.

## التراخيص
راجع شروط استخدام MapLibre وموفري بيانات الخرائط والجيوكودينغ والخدمات المستخدمة في HTML الأصلي. تأكد من عرض الإسناد المطلوب ومن عدم تجاوز حدود الاستخدام.
